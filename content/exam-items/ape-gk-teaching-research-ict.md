> **GK Units 2 and 3: Teaching aptitude, research aptitude, ICT.** These are the most scoring GK units for Assistant Professor exams (same as UGC NET Paper 1). Learn definitions, levels and abbreviations.

## A. Teaching aptitude
### Concepts
- **Teaching** = a planned interaction to bring learning. Objectives: knowledge, understanding, skills, attitude.
- **Levels of teaching**: **memory level** (Herbart; teacher-centred), **understanding level** (Morrison; insight), **reflective level** (Hunt; learner-centred, problem-solving, highest).
- **Bloom's taxonomy** (1956; revised by Anderson and Krathwohl, 2001): cognitive (remember, understand, apply, analyse, evaluate, **create**), affective (Krathwohl), psychomotor (Simpson, Harrow).
- Learner characteristics: adolescent and adult learners (**andragogy**, Malcolm Knowles), individual differences, multiple intelligences (**Howard Gardner**: 8 types).
- Factors affecting teaching: teacher, learner, support material, instructional facilities, environment, institution.

### Methods
| Teacher-centred | Learner-centred |
|---|---|
| lecture, demonstration, team teaching | discussion, project method (Kilpatrick), problem-solving, case study, **flipped classroom**, cooperative learning |

- Offline vs online: **MOOCs**, **SWAYAM** (2017; four quadrants: video, e-text, self-assessment, discussion forum), **SWAYAM Prabha** (DTH channels), NPTEL, e-PG Pathshala.
- **Blended learning**: online + face to face.

### Evaluation
- **Formative** (during learning), **summative** (end), diagnostic (find weaknesses), placement.
- **CBCS** (Choice Based Credit System), **CCE** (continuous and comprehensive evaluation), grading.
- Norm-referenced (compare with others) vs criterion-referenced (compare with a standard).
- Good test: **validity** (measures what it should), **reliability** (consistent), objectivity, usability.

## B. Research aptitude
### Meaning and types
- Research: systematic, objective search for new knowledge.
- **Fundamental (pure)** vs **applied** vs **action research** (to solve a classroom/institution problem; Stephen Corey).
- Quantitative (positivism: numbers, hypothesis testing) vs qualitative (interpretivism: meaning, case study, ethnography, phenomenology, grounded theory: Glaser and Strauss).
- **Experimental** (manipulate variable), **descriptive/survey**, **historical**, **ex post facto** (cause after effect), longitudinal vs cross-sectional.

### Steps of research
Identify problem → review literature → formulate **hypothesis** → research design → sampling → data collection → analysis → interpretation → report.

- **Hypothesis**: testable statement. Null (H₀: no relation), alternative (H₁). Good hypothesis: testable, specific, simple, consistent with known facts.
- **Variables**: independent (cause), dependent (effect), intervening, moderator, extraneous.
- **Sampling**: probability (simple random, stratified, systematic, cluster) and non-probability (convenience, purposive, quota, **snowball**).
- Tools: questionnaire, interview, observation (participant/non-participant), schedule, rating scale (**Likert**), **sociometry** (Moreno).

### Thesis and ethics
- Format: title, abstract, introduction, review, methodology, results, discussion, conclusion, references, appendix.
- Referencing styles: **APA** (author–date; psychology and social sciences), **MLA** (humanities), Chicago, Harvard.
- Ethics: informed consent, confidentiality, honesty; **plagiarism** (UGC Regulations 2018: levels by similarity: up to 10% minor; 10–40% level 1; 40–60% level 2; above 60% level 3).
- **Impact factor** (Eugene Garfield), **h-index** (Jorge Hirsch, 2005), i10-index (Google Scholar).
- UGC-CARE list for quality journals; Shodhganga (theses repository, INFLIBNET); Shodhgangotri (synopses).

### Data interpretation (basic)
- Mean, median, mode, percentages, ratios, growth rates; reading tables, bar, line and pie charts. See [Statistics notes](item.html?id=ape-u3-stats-notes).

## C. Information and Communication Technology (ICT)
### Basics
| Unit | Value |
|---|---|
| 1 byte | 8 bits |
| 1 KB | 1,024 bytes |
| 1 MB, GB, TB, PB | each 1,024 of the previous |
| Nibble | 4 bits |

- Hardware: CPU (ALU + CU + registers), memory: **RAM** (volatile), **ROM** (non-volatile), cache (fastest), secondary (HDD, SSD).
- Number systems: binary (base 2), octal (8), decimal (10), hexadecimal (16). Example: (1010)₂ = **10**.
- Software: system (OS: Windows, Linux, Android), application, utility; open source (Linux, LibreOffice).

### Internet
| Term | Meaning |
|---|---|
| WWW | invented by **Tim Berners-Lee** (1989) |
| HTTP / HTTPS | web transfer protocol (HTTPS secure) |
| TCP/IP | basic internet protocol suite |
| URL | address of a web page |
| DNS | converts domain names to IP addresses |
| IPv4 / IPv6 | 32-bit / 128-bit addresses |
| SMTP, POP3, IMAP | email sending and receiving |
| FTP | file transfer |
| LAN, MAN, WAN | network by area |
| Cc / Bcc | copy / blind copy (Bcc recipients hidden) |

- **Malware**: virus, worm, Trojan, ransomware; phishing (fake emails), spam.
- Cloud computing: **SaaS** (Gmail), **PaaS**, **IaaS**.

## D. Higher education system (often in this unit)
- UGC (1953, statutory 1956); NAAC (1994, Bengaluru); NIRF ranking (2016); **NEP 2020** (4-year UG, multiple entry–exit, HECI proposed, 50% GER by 2035).
- Kothari Commission (1964–66), Radhakrishnan Commission (1948–49, university education), National Knowledge Commission (Sam Pitroda, 2005).
- Types of universities: central, state, deemed, private; Institutions of Eminence.

## Exam traps
- Reflective level is the highest level of teaching (Hunt); memory level is Herbart's.
- Revised Bloom's taxonomy puts **create** at the top, not evaluate.
- Action research is done by practitioners to solve their own problems.
- Snowball sampling is non-probability.
- RAM is volatile; ROM is not.
- h-index was proposed by Hirsch (2005); impact factor by Garfield.
