## Formula sheet: all units on one page

### Micro
| Item | Formula |
|---|---|
| Consumer equilibrium | MRSxy = MUx/MUy = Px/Py |
| Price elasticity | ed = (ΔQ/ΔP)·(P/Q) |
| MR and elasticity | MR = P(1 − 1/ed) |
| Lerner index | (P − MC)/P = 1/ed |
| Slutsky | ∂x/∂p = ∂h/∂p − x·∂x/∂M |
| Producer equilibrium | MRTS = MPL/MPK = w/r |
| Cournot (n firms, zero cost) | each firm's output = competitive Q / (n + 1) |
| Profit maximum | MR = MC, MC rising |

|---|---|

| Tax multiplier | −c/(1 − c) |
